# Line Follower Robot – Sensor Circuit Prototyping

## Project Overview
This project focuses on designing and prototyping the IR sensor circuit for a Line Follower Robot using TCRT5000 reflective infrared sensors. 

The sensor circuit is designed to detect differences between light and dark surfaces by sensing reflected infrared light. The project involved circuit simulation, hardware prototyping, and PCB implementation.

---

## Objectives
* Understand the working principle of TCRT5000 reflective IR sensors.
* Design an IR sensor circuit for line detection applications.
* Simulate and verify the circuit design using Proteus.
* Implement the circuit through hardware prototyping.
* Explore custom PCB design for the sensor circuit.

---

## Components and Tools
* TCRT5000 IR Reflective Sensor
* Electronic components used in the sensor circuit
* Proteus Design Suite
* Veroboard
* Custom PCB

---

## Development Process
1. **Circuit Design:** Designed the IR sensor circuit using TCRT5000 sensors.
2. **Simulation:** Developed and tested the circuit design in Proteus.
3. **Hardware Prototyping:** Implemented the circuit on veroboard to evaluate its hardware operation.
4. **PCB Implementation:** Designed and prepared a custom PCB for the sensor circuit.

---

## Applications
* Line detection
* Line Follower Robots
* Reflective surface detection

## Project Scope
This project covers the sensor circuit design and prototyping stage of a Line Follower Robot. It does not represent a complete robot implementation.

# 2D Floor Layout

A 2D floor layout prepared as part of an academic laboratory project.

## 📐 Project Overview

This project involved **measuring an existing floor layout and converting the measurements into a structured 2D floor plan**.

The drawing represents the spatial arrangement of rooms, corridors, stairs, lift areas, and other architectural elements based on measurements taken during the laboratory work.

## 🛠️ Work Performed

* Conducted on-site measurements of the floor layout
* Recorded room and structural dimensions
* Translated measurements into a 2D floor plan using AutoCAD
* Maintained relative dimensions and spatial relationships
* Organized rooms, corridors, stairs, and other structural elements
* Prepared the final drawing for documentation and academic purposes

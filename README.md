# My Engineering & Electronics Projects

Welcome to my project showcase! This repository contains documentation, PCB layouts, schematics, and media for my hardware and embedded systems projects.

## Projects List
### 1. Temperature-Controlled DC Fan (PTC-Based)
- **Description:** Designed and built a dynamic temperature-controlled DC fan circuit utilizing an Op-Amp 741 IC and a thermistor for automatic speed regulation based on thermal changes.
- **Features:** Custom PCB design, Op-Amp comparator/amplifier logic and thermistor integration.

### 2. Variable DC Power Supply & Rectifier Circuit
- **Description:** Fabricated a regulated AC-to-DC converter circuit step-down transformer, full-wave bridge rectifier, filtering capacitors and a potentiometer for variable DC voltage output.
- **Features:** Transformer voltage step-down, AC-to-DC rectification, voltage ripple filtering, and adjustable output control.
- **Year:** 2023

### 3. Smart Home Automation using ESP8266
- **Description:** Developed an IoT-based smart home control system using the ESP8266 Wi-Fi module to control electronic appliances remotely via a wireless network.
- **Features:** Microcontroller programming, Wi-Fi networking, relay module switching, and remote appliance control.

### 4. Line Follower Robot Sensor Circuit (TCRT5000)
- **Description:** Designed and manufactured a custom IR sensor module PCB for a Line Follower Robot using TCRT5000 optical sensors for precise line detection and surface tracking.
- **Features:** Custom PCB layout, IR emitter/receiver pair integration, and analog-to-digital switching logic.
